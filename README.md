One line, in a dog's own voice, explaining why the homework got eaten — written to `/output/entry.txt` for make.fun's **The Dog Ate My Homework: Funniest Excuse** bounty.

## The excuse

> I only ate the answers — the questions are buried in the yard if you still need them.

The joke is dog logic with zero embarrassment: the dog did nothing wrong, it just filed the answers away (in its stomach) and helpfully archived the questions underground, where all good things go.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` (Python 3.13, standard library only) writes the fixed 85-character line to `/output/entry.txt`. It is deterministic: two runs write byte-identical output, well inside the 1–200 character gate.
